# Business Analyst Command Center

A responsive React portfolio app that presents a business analyst workspace for initiative triage, requirements traceability, risk tracking, stakeholder pulse, and process bottleneck analysis.

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- Vite
- Lucide React

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
